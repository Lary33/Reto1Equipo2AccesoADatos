# Gestión de Videojuegos

## ¿Cómo funciona la página?

Al entrar en la web aparece un menú desde el que podemos acceder a tres categorías: **videojuegos, consolas y periféricos**.

Para desplazar la nave se debe utilizar el ratón y solo se mueve en el eje horizontal. Para entrar en una de estas categorias se deberá hacer click, lo que dispará una bala que al impactar con el elemento abrira su CRUD.

En cada categoría podemos ver los elementos guardados y consultar sus detalles. También podemos **añadir nuevos elementos, editar los que ya existen o eliminarlos**.

Los datos se guardan en archivos CSV, por lo que los cambios realizados desde la página quedan registrados.

## ¿Cómo entrar?

Ejecutamos el proyecto y abrimos `http://localhost:8080` en el navegador.
